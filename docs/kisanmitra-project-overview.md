# KisanMitra2 - Project Overview

## Purpose
KisanMitra2 is an Android application intended to support
farm management and agricultural labour management.

## Main Application Areas
- Dashboard
- Labour Management
- Farm Management
- Crop Management
- Crop Stage Management
- Agricultural Task Management
- Labour Assignment
- Voice-Assisted Attendance
- Wage Calculation
- Organic Farming Guide
